# Коды ЧЗ — выгрузка на терминал (Flutter, Windows)

## Сборка exe в один клик

В корне проекта запустите:

```
.\build_release.bat
```

(в терминале VS Code; или двойным щелчком по файлу в Проводнике)

Скрипт последовательно выполнит: `flutter clean` → `pub get` → `analyze` →
`test` → `build windows --release` → подготовку папки для переноса.
Если любой шаг упадёт — остановится и покажет, на каком именно.

**Результат:**

| Что | Где |
|---|---|
| Папка для запуска и переноса | `dist\HonestSignManager\` |
| Сам exe | `dist\HonestSignManager\honest_sign_manager.exe` |
| Архив для отправки коллегам | `dist\HonestSignManager_portable.zip` |

> Переносить нужно **всю папку целиком**. Рядом с exe лежат `flutter_windows.dll`,
> `sqlite3.dll` и папка `data\` — без них приложение не запустится.

## Установщик (необязательно)

1. Установите [Inno Setup 6](https://jrsoftware.org/isinfo.php).
2. Выполните `build_release.bat` (должна появиться папка `dist\HonestSignManager`).
3. Откройте `installer.iss` → **Build → Compile**.
4. Получится `dist\HonestSignManager_Setup_1.0.0.exe` — обычный установщик
   с ярлыками и деинсталлятором.

## Что требует установки

| Компонент | Зачем |
|---|---|
| Flutter SDK 3.24+ | сборка |
| Visual Studio 2022 | компилятор C++ — **не VS Code** |
| Компонент «Разработка классических приложений на C++» | он же, при установке VS |

Проверка: `flutter doctor -v` — напротив *Visual Studio* должна быть галочка.

## Первый запуск приложения

1. «Настройки» → вставить токен → «Сохранить токен».
2. «Настройки» → «Импортировать из Excel» → файл со списком товаров (столбец A — ID, B — наименование).
3. «Выгрузка» → перетащить файл с кодами (столбец B) → адрес терминала → товар → «Выгрузить коды».

## Где хранятся данные

- История и справочник: `%APPDATA%\SYNTX\honest_sign_manager\honest_sign.db`
  (точный путь показан внизу вкладки «Настройки»).
- Токен и последние адреса: `shared_preferences` в том же каталоге.

## API терминала

| Действие | Метод | Путь | Тело |
|---|---|---|---|
| Загрузка | POST | `/v1/honest-sign/codes/bulk` | `{"bulk":[{"code":"<base64>","productId":77}]}` |
| Удаление | DELETE | `/v1/honest-sign/codes/delete/bulk` | `{"codes":["<base64>", ...]}` |

Заголовок: `Authorization: Bearer <токен>`.
Путь добавляется к введённому адресу как есть:
`http://IP:порт/api` → `http://IP:порт/api/v1/honest-sign/codes/bulk`.
