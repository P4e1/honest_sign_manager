# Коды ЧЗ — выгрузка на терминал (Flutter, Windows)

## Общая история на файловом сервере

История выгрузок хранится на сетевой папке — её видят все пользователи.

```
\\192.168.2.11\obmen\Работа\HonestSignManager для весовых терминалов\
├── store\
│   ├── records\2026\20261026-081500-4f2a.json   ← одна выгрузка = один файл
│   └── tombstones\20261026-081500-4f2a.json     ← отметка «удалён»
└── (локальный кеш каждого пользователя хранится в его профиле)
```

Файлы записей создаются один раз и после этого никогда не меняются,
поэтому несколько человек могут работать одновременно без конфликтов.

Локальный кеш (`%APPDATA%\...\cache.db`) служит только для скорости:
его можно удалить, он построится заново из файлов на шаре.

### Если шара недоступна

Приложение продолжает работать:
- история показывается из локального кеша;
- выгрузка на терминал не блокируется — запись сохраняется локально
  и автоматически досылается на шару при следующей синхронизации;
- сверху появляется предупреждение, что данные могут быть неполными.

### Синхронизация

Происходит автоматически при открытии вкладки «История» и перед выгрузкой.
Кнопка «Обновить» — принудительно. Внизу показано время последней синхронизации.

## Сборка exe в один клик

```
.\build_release.bat
```

Шаги: `clean` → `pub get` → `analyze` → `test` → `build windows --release` → упаковка.

| Что | Где |
|---|---|
| Папка для запуска | `dist\HonestSignManager\` |
| exe | `dist\HonestSignManager\honest_sign_manager.exe` |
| Архив для коллег | `dist\HonestSignManager_portable.zip` |

Переносить нужно **всю папку целиком** (рядом лежат dll и папка `data`).

## Установщик (необязательно)

1. Установите [Inno Setup 6](https://jrsoftware.org/isinfo.php).
2. Выполните `build_release.bat`.
3. Откройте `installer.iss` → **Build → Compile**.

## Первый запуск

1. «Настройки» → токен → «Сохранить токен».
2. «Настройки» → «Импортировать из Excel» → справочник товаров (A — ID, B — наименование).
3. «Настройки» → «Файловый сервер» → проверить путь → «Проверить доступ» → «Сохранить».
4. «Выгрузка» → перетащить файл с кодами (столбец B) → адрес терминала → товар → «Выгрузить коды».

## Права на папку

Пользователям Windows нужны права **«Изменить»** на папку из `storePath`
(и подпапки). Стандартная авторизация Windows — отдельные учётные данные не нужны.

## API терминала

| Действие | Метод | Путь | Тело |
|---|---|---|---|
| Загрузка | POST | `/v1/honest-sign/codes/bulk` | `{"bulk":[{"code":"<base64>","productId":77}]}` |
| Удаление | DELETE | `/v1/honest-sign/codes/delete/bulk` | `{"codes":["<base64>", ...]}` |

Заголовок: `Authorization: Bearer <токен>`. Путь добавляется к введённому адресу как есть.
